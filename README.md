# SHOGI_AI

## Quels problèmes je résous ?

**SHOGI_AI** permet de :
- Développer un projet complexe en **solo**
- Implémenter un jeu d'une certaine **complexité** (déterminer celle-ci)
- Tenter de résoudre le jeu en développant des **modèles d'IA**
- Et optionnellement développer une **interface graphique** convivial

## Qui est l'utilisateur type ?

En fonction de l'IA choisie (je compte implémenter 2 IA), les utilisateurs pourront soit être des **personnes découvrant le SHOGI**(une IA limité suivi potentiellement d'un tutoriel) soit des **joueurs expérimentés** souhaitant se challenger (je donnerai toutes mes connaissances dans le but de faire l'IA la plus complète possible jouant en moins de 100 ms).

## Quels sont les applications concurrentes ?

Je ne me baserai que sur le concept de Shogi, jeu que je connais assez bien.

## Comment je me différencie ?

La particularité de ce projet sera l'utilisation la plus limité possible dans la phase de développement et de conception concrète, l'utilisation de l'IA sera rigoureusement documentée durant la durée du projet.
